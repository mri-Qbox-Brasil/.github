### Visão Geral

A MRI Brasil é uma iniciativa técnica focada em solucionar os principais gargalos do desenvolvimento de servidores FiveM: dependências ultrapassadas, código mal otimizado e perda excessiva de tempo com configurações repetitivas.

Adotamos a framework Qbox em integração nativa com o ecossistema Overextended (Ox), fornecendo automações, conectores e ferramentas que entregam um ambiente pronto no primeiro start para quem cria cidades e mecânicas.

### Pilares de Desenvolvimento

* Desempenho por Arquitetura: Recursos em Lua e TypeScript desenvolvidos para manter o consumo de resmon mínimo no cliente e no servidor.
* Ecossistema Ox Nativo: Integração direta com ox_lib, ox_inventory e ox_target sem necessidade de pontes lentas ou adaptações improvisadas.
* Menos Configuração, Mais Criação: Disponibilização do instalador automatizado (mri_installer) e conectores centrais (mri_Qbox, mri_lib) para agilizar o setup de banco de dados, FXServer e dependências em minutos.
* Padronização e Usabilidade: Scripts completos traduzidos em PT-BR, com documentação técnica e guias de migração para desenvolvedores.

### [EN] About MRI Brasil

MRI Brasil is an open source initiative providing developer tooling, performance optimizations, and deployment automation for FiveM servers.

By building on top of the Qbox framework and Overextended (Ox) libraries, MRI Brasil delivers an automated setup pipeline and optimized runtime connectors, allowing developers to spend less time configuring infrastructure and more time building gameplay systems.
